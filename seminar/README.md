# 那須研究室 ゼミ紹介サイト

東海大学理学部情報数理学科・情報数理第2研究室の学生向け紹介ページです。

## 公開方法

このフォルダーを GitHub Pages 用リポジトリ `hirokazunasu.github.io` の `seminar/` ディレクトリに配置してください。
公開URL: `https://hirokazunasu.github.io/seminar/`

## 構成

- `index.html`: 本文（テーマ、講読書、写真、卒業研究、進路、配属情報）
- `style.css`: デザイン、レスポンシブ対応
- `script.js`: あみだくじ体験、装飾曲線
- `images/`: ゼミ室と過去のゼミ活動の写真

## 公開前の確認事項

- 人物写真の利用許諾、公開時の説明（過去のゼミ風景）
- 2027年度の開講科目・選考方法・連絡手段
- 卒業生の就職先の企業名表記および公開範囲
- 2025年度発表題目の公開範囲（氏名・学籍番号は掲載していません）
- 学園誌記事は転載せず、教育方針を新たな文章で紹介しています。

外部CDN等への依存はありません。
